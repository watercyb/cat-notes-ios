# Cat Notes iOS

A native iOS note-taking application for creating, managing, and organizing personal notes. It integrates with the shared Cat Notes backend API to provide note management and account synchronization across web, Android, and iOS platforms.

## Features

- **Note Management:** Create, view, edit, and delete notes.
- **Secure Notes:** Create and manage private notes with additional security features.
- **User Authentication:** Authenticate users and manage account access through Clerk.
- **Backend API Integration:** Communicate with the Cat Notes REST API for note management and data synchronization.
- **Local Data Storage:** Persist and manage note data using SwiftData.
- **Native iOS Interface:** Provide a native experience for creating and managing notes.

## Technologies

- Swift
- SwiftUI
- SwiftData
- Alamofire
- Clerk
- REST APIs
- Xcode

## Technical Highlights

- Developed a native iOS application using Swift.
- Used SwiftData for local data persistence and note management.
- Integrated Clerk for user authentication.
- Used Alamofire for HTTP networking and REST API communication.
- Integrated with a shared backend API used by the web and Android applications.

## Requirements

- Compatible iOS version: iOS 18.6.
- Xcode: Version 26.2.
